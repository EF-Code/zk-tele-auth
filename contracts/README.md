# Contract composition boundary

The generated verifier core proves the Priva circuit relation. The wrapper remains a cryptographic-only test harness. `priva_purchase_launchpad.tolk` is the repository's native-TON composition: it consumes the core synchronously, binds the executing basechain address and actual sender recipient, persists action nullifiers and cumulative identity totals, enforces immutable native-TON pricing/inventory policy, and records overpayment as a canonical refundable credit after reserving storage. It intentionally records entitlements rather than pretending to settle a jetton/NFT; that downstream adapter and credit withdrawal still require an independent economic review. `npm run check:priva-composition` remains blocked until that review record exists.
